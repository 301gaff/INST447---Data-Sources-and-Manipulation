# INST447---Data-Sources-and-Manipulation
# This course examines approaches to locating, acquiring, manipulating, and disseminating data. We study practical methods for gathering data (for example, APIs and basic web data), transforming common formats (CSV, JSON, and XML), cleaning and validating tables, and completing wrangling tasks such as aggregation, subsetting, merging, and reshaping. Consistent with current professional practice, students are encouraged to try AI coding assistants and LLM tools for coding support and data tasks.

# Lectures. Conceptual foundations and live demonstrations of data acquisition, cleaning, transformation, and validation, including examples of specifying tasks precisely and checking outcomes.

# Labs. Guided, hands-on practice applying the previous lecture’s concepts. Labs use Colab notebooks and are graded for attendance and completion.

# Programming assignments. Four more rigorous checkups that consolidate recent skills. Students submit working notebooks and any requested supporting material through ELMS.

# Take-home midterm project. A practical assessment that applies an instructor-provided analysis plan to a small, realistic data task.

# Final project. An end-to-end analysis in which students select a public dataset, develop a plan, execute the analysis, and produce a stakeholder-oriented report.
